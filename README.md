# Nexus Server Manager

Gerenciador de servidores de jogos para Windows.

**[Baixar Nexus 1.0.5 para Windows — 11,5 MB](https://github.com/fabriciodba/nexus-server-manager/releases/download/v1.0.5/Nexus-Server-Manager-1.0.5.zip)**

Extraia o ZIP e execute `NexusServerManager.exe`. O pacote contém cinco arquivos; as pastas de uso são criadas na primeira abertura.

Requer Windows de 64 bits e .NET Framework 4.7.2 ou superior.

Para receber novas versões, abra **Ajuda → Atualizações do Nexus → Verificar agora**. Pare os servidores antes de aplicar a atualização.

[Ver versão publicada](https://github.com/fabriciodba/nexus-server-manager/releases/latest)
