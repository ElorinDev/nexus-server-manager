# Nexus Server Manager

Gerenciador de servidores de jogos para Windows.

**[Baixar o software para Windows](https://github.com/fabriciodba/nexus-server-manager/releases/latest)**

Na página da versão, baixe o único ZIP do programa. Extraia a pasta e execute `NexusServerManager.exe`.

Requer Windows de 64 bits e .NET Framework 4.7.2 ou superior.

As próximas versões podem ser instaladas em **Ajuda → Atualizações do Nexus → Verificar agora**. Pare os servidores antes de atualizar.

**Migração para a 1.0.6:** quem utiliza a 1.0.4 ou 1.0.5 precisa instalar o ZIP novo uma vez, preservando as pastas de dados. Depois, as atualizações continuam pelo aplicativo.
